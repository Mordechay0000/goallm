# יוטיוב – אישור סרטון בודד

## איך זה עובד

1. יוטיוב מוריד וידאו מ-`*.googlevideo.com/videoplayback`. המזהה בכתובות האלה (`id=o-…`) **משתנה בכל טעינה**, ולכן אי אפשר לדעת מהכתובת איזה סרטון זה.
2. הזהות היציבה (videoId) מופיעה רק ב"תשובת הנגן" שהדפדפן מקבל:
   - `ytInitialPlayerResponse` בתוך דף הצפייה;
   - JSON מ-`youtubei/v1/...` בניווט בתוך האתר ובסרטונים מוטמעים.
3. הפרוקסי מחליט שם, לפי videoId:
   - **לא אושר:** תשובת הנגן הופכת לצורה של "לא ניתן לנגן", אותה צורה שיוטיוב עצמו משתמש בה. הנגן מציג את ההודעה שלנו, ומעליו לחצן **"שלח לבדיקה"**.
   - **אושר:** התשובה עוברת, ומזהי הזרמים שבה נרשמים כמאושרים לכמה שעות. זה כולל וידאו, שמע ו-SABR.
4. **כל זרם googlevideo שהמזהה שלו לא נרשם – נחסם.** אם יוטיוב ישנה פורמט ותשובה תחמוק, התוצאה היא נגן שבור, לא סרטון לא בדוק.
5. שידור חי חסום תמיד, כי אי אפשר לבדוק אותו מראש.

נבדק בדפדפן אמיתי (Chromium דרך הפרוקסי) מול youtube.com:
- הנגן הציג את הלחצן;
- לחיצה רשמה את הסרטון לבדיקה לפי videoId;
- כל בקשות googlevideo נחסמו.

**לא נבדק כאן:** ניגון של סרטון מאושר. יוטיוב דרש מהשרת הזה "אימות שאינך בוט", כך שאף סרטון לא התנגן גם בלי הסינון.

## מה לאשר ברשימה הלבנה

כדי שיוטיוב ייפתח בכלל (הסרטונים עצמם נשארים חסומים עד אישור), צריך כללים גלובליים **כולל תת-דומיינים** ל:

- `youtube.com`
- `googlevideo.com`: הזרמים, תחת `rr1---sn-xxxx.googlevideo.com`
- `ytimg.com`: תמונות ממוזערות, ועוברות בסינון התמונות
- `ggpht.com`: תמונות ערוצים
- `youtube-nocookie.com`: סרטונים מוטמעים באתרים אחרים

אסור לסמן ב-`youtube.com` או ב-`googlevideo.com` "וידאו פתוח לאתר" (`video_filter_enabled = False`). זה פותח את כל הסרטונים ועוקף את האישור הבודד.

## בודק הסרטונים (הורדה מיוטיוב)

הבודק מוריד דרך `yt-dlp` (נמצא ב-`requirements.txt`): וידאו עד `VIDEO_YTDLP_MAX_HEIGHT` (ברירת מחדל 720) ופס הקול לבדיקת קול אישה.

**בעיה ידועה:** יוטיוב מגביל הורדות משרתי ענן. בבדיקה כאן `yt-dlp` קיבל את פרטי הסרטון, אבל ההורדה עצמה קיבלה 403. במקרה כזה הבודק מסמן שגיאה עם הסבר. פתרונות, לפי הסדר:

1. **`YTDLP_PROXY`**: פרוקסי ביתי או בכתובת קבועה של ספק ישראלי. בדרך כלל זה מה שפותר.
2. **`YTDLP_COOKIES_FILE`**: קובץ cookies.txt של חשבון ייעודי (לא אישי).
3. **תוסף PO-token ל-yt-dlp** (`pip install bgutil-ytdlp-pot-provider` + השרת שלו).
4. **לעדכן את `yt-dlp` לעתים קרובות** (`pip install -U yt-dlp`). יוטיוב משנה דברים, ו-yt-dlp מתעדכן בהתאם.

## מגבלות

- **Vimeo, Wistia, פייסבוק ושאר האתרים:** הווידאו חסום (fail-closed), אבל אין מיפוי של "אישור סרטון בודד" כמו ביוטיוב. אפשר לפתוח אתר שלם לווידאו בכלל גלובלי.
- **אפליקציית יוטיוב בטלפון:** לא עובדת דרך הפרוקסי (ראו [`ANDROID.he.md`](ANDROID.he.md)). רק דרך הדפדפן.
- **סרטון שאושר נפתח לכולם**, כמו בנטפרי. אישור הוא לפי videoId, ולא לפי משתמש.

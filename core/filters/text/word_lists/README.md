# רשימות מילים לסינון מלל

- **קובץ אחד לשפה**: `he/blocked.txt`, `en/blocked.txt`.
- **הכלל:** רק מילה שכל משמעות שלה היא התוכן הלא צנוע עצמו. **לא נכנסת מילה שמופיעה בהקשר מותר**: תורה והלכה (גם בתרגום), חדשות חרדיות, רפואה, טפסים, או שיש לה משמעות יומיומית.
  - לדוגמה "מין" (= סוג, זכר/נקבה), "לא תנאף", "ויהיו שניהם ערומים", "Sex: M/F".
  - סיבות ההסרה של כל מילה כתובות בראש כל קובץ.
- **נושא מול תוכן:** מילים שמתארות נושא שנדון גם בהקשר מותר (להט"ב בחדשות, אוננות בהלכה, ליבידו בעלון תרופה) לא ברשימה. דף שמקדם נושא כזה נתפס לפי ההקשר: חוות הדעת של המודל (`TEXT_LLM_REVIEW`).
- **התאמה:**
  - עברית: המילה ונטיותיה (ים / ות / ית / יות / י), עם אותיות שימוש (ו ה ב ל כ מ ש) לפניה.
  - אנגלית: stemming.
  - שורה שמתחילה ב-`=` מתאימה רק כמו שהיא.
- **לפני ואחרי כל שינוי:** `python -m tools.check_word_list <קבצי טקסט מותר>` מדפיס כל התאמה בהקשר שלה. כל התאמה היא מילה לתקן.
  - הרשימה הנוכחית: אפס התאמות על תנ"ך, משנה, רמב"ם, שו"ע, קיצור ומשנ"ב (עברית ואנגלית) ו-110 כתבות מאתרי חדשות חרדיים.
- פורמט: שורה שמתחילה ב-`#` מתעלמת. מילה אחת לשורה.
